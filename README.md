# Telegram-магазин женской одежды

Полноценная система: каталог для покупателей, оформление заказа без онлайн-оплаты,
склад (размер/цвет/остатки), заказы со статусами и статистика продаж.

## Что внутри
- `server.js`, `bot.js`, `db.js`, `routes/*` — backend на Express + Telegraf + SQLite (файл `shop.db` создаётся автоматически)
- `webapp/index.html` — каталог для покупателей (Telegram Mini App)
- `webapp/admin.html` — админ-панель (товары, склад, заказы, статистика)

## Шаг 1. Создать бота
1. Напишите **@BotFather** в Telegram → `/newbot` → следуйте инструкциям.
2. Скопируйте токен — это `BOT_TOKEN`.
3. Узнайте свой Telegram ID у **@userinfobot** — это `ADMIN_IDS`.

## Шаг 2. Установить зависимости
```bash
npm install
```

## Шаг 3. Задеплоить на хостинг с HTTPS
Telegram Mini Apps работают **только по HTTPS**, локальный `localhost` не подойдёт.
Проще всего — бесплатные варианты:
- **Railway.app** — залить репозиторий, добавить переменные окружения, деплой автоматический
- **Render.com** — то же самое, тип сервиса Web Service
- Свой VPS + Nginx + Let's Encrypt, если уже есть сервер

После деплоя скопируйте выданный HTTPS-адрес (например `https://telegram-shop-production.up.railway.app`).

## Шаг 4. Заполнить переменные окружения
Скопируйте `.env.example` в `.env` и заполните:
```
BOT_TOKEN=токен_от_botfather
WEBAPP_URL=https://ваш-домен-с-хостинга
ADMIN_IDS=ваш_telegram_id
```

## Шаг 5. Запуск
```bash
npm start
```
Бот и сервер запускаются вместе одной командой.

## Как пользоваться
- Покупатель пишет боту `/start` → открывает каталог → выбирает размер/цвет → оформляет заказ (имя, телефон, комментарий) → вам приходит уведомление в Telegram с деталями заказа для связи с клиентом.
- Вы (админ) пишете боту `/start` или `/admin` → видите отдельную кнопку «Админ-панель»:
  - **Товары** — добавление/редактирование, фото по ссылке, варианты размер+цвет+остаток, +/− на складе одним тапом
  - **Заказы** — фильтр по статусу, подтверждение/выполнение/отмена
  - **Статистика** — выручка, топ товаров, что заканчивается на складе, график по дням

## Важные ограничения текущей версии
- Оплата не встроена — как и просили, заказ фиксируется, дальше вы связываетесь с клиентом сами (звонок/перевод).
- Фото товаров указываются по прямой ссылке (URL), загрузка файлов не реализована — при желании можно добавить загрузку в облако (например, Cloudinary) следующим шагом.
- Проверка подлинности `initData` от Telegram упрощена (админ-доступ проверяется по ID) — для продакшена с большим потоком заказов стоит добавить HMAC-валидацию `initData` на сервере.
